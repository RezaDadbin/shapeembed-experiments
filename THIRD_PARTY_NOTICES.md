## ShapeEmbed

Original method: A. Foix-Romero, C. Russell, A. Krull, and V. Uhlmann, **ShapeEmbed: a self-supervised learning framework for 2D contour quantification**, NeurIPS 2025. [Paper](https://openreview.net/forum?id=iT2ZisemFs); [official implementation](https://github.com/uhlmanngroup/ShapeEmbed).

The legacy circular ResNet/model wrapper and related loss, evaluation, and preprocessing routines adapt the official implementation. The main 2D implementation also follows its architecture and objective. The collected official checkout used as a reference was commit `da515f9`; the mask-conversion reference checkout was `71491b0`.

Both [ShapeEmbed](https://github.com/uhlmanngroup/ShapeEmbed/blob/main/LICENSE) and [ConvertBinaryMasksToDMs](https://github.com/uhlmanngroup/ConvertBinaryMasksToDMs/blob/main/LICENSE) are distributed under MIT, copyright 2025 Uhlmann Group. The complete permission and warranty notice is retained in this repository's [LICENSE](LICENSE), together with the copyright for project contributions. The upstream repositories are references, not claimed as original work by this project's author.

The model uses torchvision's ResNet implementation through the installed dependency. Dependency packages retain their own licenses; their source distributions are not bundled here.

## Data

**BBBC010 v1:** C. elegans infection live/dead images and individual-worm masks, provided by Fred Ausubel and the [Broad Bioimage Benchmark Collection](https://bbbc.broadinstitute.org/BBBC010). The dataset page identifies the images as CC0 and requests citation of Ljosa et al., *Nature Methods* (2012). The preprocessing illustration contains small examples from those masks. The organizer downloads the dataset from its original host; the raw image archive is not bundled.

**MNIST:** handwritten-digit data accessed through `torchvision.datasets.MNIST`. The raw images and processed arrays are not bundled. The historical project uses a new split of the combined images; see [results](docs/results.md).

**Synthetic 3D primitives:** generated by this project's `phase3/generate_dataset.py`. Selected reconstruction/interpolation figures and archived result records are included as project artifacts.

**Topology diagrams:** project-generated geometric examples and architecture schematics. They are labeled as illustrations or proposals and do not depict outputs of a trained topology-aware model.

## Project scope

Reza Dadbin's project contributions include the experimental integration, architecture comparisons, the 3D surface prototype and ablations, and extension design notes. The public packaging adds portability fixes, tests, faithful plotting defaults, and explicit result provenance.

Private assignments, recovered conversations, local collection inventories, unrelated source variants, datasets, large checkpoints, and old Git history are excluded from this repository. The original paper PDF is linked rather than redistributed.
